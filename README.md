# Product Review Sentiment Analyzer

A Python-based Natural Language Processing (NLP) tool that performs batch sentiment analysis on e-commerce product reviews and visualizes the results using an interactive scatter plot[cite: 2].

## 🚀 Features
* **Automated Sentiment Scoring:** Uses `TextBlob` to calculate polarity (negative vs. positive) and subjectivity (objective vs. subjective) for a dataset of product reviews[cite: 2].
* **Terminal Categorization:** Dynamically classifies text and outputs color-coded status logs directly in the terminal[cite: 2].
* **Data Visualization:** Generates a clean `Matplotlib` scatter plot mapping polarity against subjectivity with custom color coding and reference threshold lines[cite: 2].

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** 
  * `textblob` (for NLP sentiment analysis)[cite: 2]
  * `matplotlib` (for data visualization)[cite: 2]
