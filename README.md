# Product Review Sentiment Analyzer

A Python-based Natural Language Processing (NLP) tool that performs batch sentiment analysis on e-commerce product reviews and visualizes the results using an interactive scatter plot

## 🚀 Features
* **Automated Sentiment Scoring:** Uses `TextBlob` to calculate polarity (negative vs. positive) and subjectivity (objective vs. subjective) for a dataset of product reviews.
* **Terminal Categorization:** Dynamically classifies text and outputs color-coded status logs directly in the terminal.
* **Data Visualization:** Generates a clean `Matplotlib` scatter plot mapping polarity against subjectivity with custom color coding and reference threshold lines.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** 
  * `textblob` (for NLP sentiment analysis)
  * `matplotlib` (for data visualization)
